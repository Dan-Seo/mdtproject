# Step 2: 산정·数量·3D가 비대칭을 담는다 — 골든 먼저

## 배경

step 1의 `decomposeGirderMainRow`를 엔진에 잇는다. **대칭 입력의 출력
(数量·formula·3D)은 하나도 달라지면 안 된다** — 기존 골든·테스트가 그것을
보증한다. 형상·길이 규칙은 ADR-032 §4·§5를 따른다.

## 할 일

1. **골든 먼저 (TDD)** — `tests/golden/`의 기존 관례(픽스처에 terms 독립
   전사 ＋ 수계산, ADR-010 — `fabrication-length.json`의 `derivedBy` 참조):
   - 단일 스팬 비대칭 케이스 둘을 加工長·数量(設計長さ·本数·継手箇所) 골든에
     추가: **스텁형** G51 R階 기반(上 8/8/13·下 8/8/11, D25 — 終端스텁만
     위 5본·아래 3본, 始端 스텁 없음)과 **혼합형** G55 R階 기반(上 4/5/8·
     下 4/5/5 — 上은 편측근(終端定着) 1본＋終端스텁 3본, 下는 편측근 1본).
   - 치수(内法·지점 축방향 せい·カットオフ位置·かぶり 조건)는 픽스처 입력으로
     명기하고, 기대값마다 산식을 주석으로 남겨라. 수계산은 픽스처의 terms만
     쓰고 `lookupRule`을 통하지 마라.
   - **다스팬 런 × 비대칭 → `MemberUnsupportedError`** 테스트 (ADR-032 §5).
2. `src/domain/rebar/girder.ts`:
   - rows의 split을 `decomposeGirderMainRow`로 바꾼다.
   - **스텁을 좌우로 분리** — 비대칭이면 해당 支点 쪽에만, 位置별 본수로.
     束ね 규약(積算基準 前文 「規格、形状、寸法等ごとに」)은 유지 — 양쪽의
     設計長さ·본수가 같으면 지금처럼 1행으로 묶는다.
   - **편측근**: 한쪽 支点 定着(`resolveGirderEnd` — 기존 스텁과 같은 경로)
     ＋ (内法 − カットオフ位置). 継手는 `intervalSplice` 그대로. formula는
     기존 문형으로 산식 전부를 싣는다.
   - **中央筋**: 기존 中央 경로 재사용 (일반화만).
   - **다스팬(run.spans.length > 1) × 비대칭(s≠e인 행 존재) →
     `MemberUnsupportedError`**. 코드명은 기존 'カットオフ位置不成立' 관례로
     지어라. 사유에 「外端/内端이 런의 어느 支点인지 정할 수 없다」를 담아라.
   - 기존 검사(カットオフ位置 > 0, 内法 > 2×位置)는 새 항(편측근·中央筋)이
     있을 때도 적용하라.
3. `src/lib/viewer/geometry.ts`: `girderMainPlacements`를 분해에 맞춰라.
   불변식 — **각 x구간 단면의 본수가 始端 s·中央 c·終端 e와 일치**하고,
   같은 x구간에서 같은 枠에 두 그룹이 겹치지 않는다. `splitGirderMainRow`의
   잔존 호출을 이관하고, 이관이 끝나 고아가 된 옛 함수는 member.ts에서
   제거하라 (이 변경이 만든 고아만).
4. **대장 갱신**: `CLAUDE.md`·`AGENTS.md`의 R13 행 — 모델·산정 제약 해소
   (ADR-032), 남은 것은 입력 경로(断面一覧 편집·断面リスト 취입의 라벨↔
   始終端 대응). `docs/RISKS.md` R13에 같은 취지를 추기하고 nesting 해석이
   조문 아닌 판단(R2)임을 남겨라. 어투·길이는 표의 다른 행과 맞춰라.

## 하지 말 것

- `src/lib/import/**`·`src/components/**` 수정 금지 — 입력 경로는 다음 phase다.
- 대칭 입력의 출력을 바꾸지 마라. **기존 골든 기대값 수정 금지** — 수정이
  필요해 보이면 `blocked`로 멈추고 사유를 적어라.
- 배근 규준 수치를 코드에 쓰지 마라 — 定着·継手는 전부 룰팩 조회다.
- `Project` schemaVersion 변경 금지.
- `scripts/execute.py`를 실행하지 마라 — 재귀다.

## AC

- 골든 포함 `npm run test`·`npx tsc --noEmit`·`npm run lint` 전체 통과.
- 새 골든의 기대값이 수계산 주석과 함께 있고, 구현을 흔들면(예: 편측근
  길이에서 カットオフ位置를 빼지 않으면) 실패한다.
- 다스팬×비대칭 불성립 테스트가 존재한다.
- 기존 테스트·골든 전부 무변경 통과. 대장 갱신 포함.
