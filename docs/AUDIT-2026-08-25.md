## 미확인 (근거를 못 붙인 것)

- **e2e(`tests/e2e/`)의 반증력은 재지 않았다.** 4절 3번째 버킷을 `tests/section-import/`로 잡았고, e2e는 dev 서버 기동이 필요해 이 감사에서 돌리지 않았다. 「build → dev 기동 → e2e」 순서 제약(CLAUDE.md)도 있어 별도 세션이 맞다.
- **`src/components/`의 22개 프로덕션 파일(Viewer3D.tsx 2110줄 포함)은 중복 관점에서 훑지 않았다.** 3절의 지시가 domain↔lib이었다. 3-10은 중복 탐지 스크립트에 걸린 것만 적었고 계통 조사가 아니다.
- **`import` 그래프는 정규식 파싱이다.** 타입스크립트 AST가 아니라 `import ... from`·bare import·동적 `import()` 세 모양을 정규식으로 잡았다. 조건부 `require`나 문자열 연결로 만든 경로가 있으면 놓친다 — 그런 코드는 확인하지 않았다.
- **`transcribed` 237행이 원문과 맞는지는 이 감사가 확인하지 않았다.** 확인한 것은 「`source`·`confidence` 필드가 존재하고 `sources.yaml`이 선언한 ref만 쓴다」까지다. 원문 대조는 R6이고 사람 몫이다.
- **`inferred` 3행이 어느 항목인지 개별 확인하지 않았다.** 히스토그램만 셌다.
- **테스트가 없는 프로덕션 파일 목록을 만들지 않았다.** 4절이 표본 반증을 요구했지 커버리지 집계를 요구하지 않았다.
