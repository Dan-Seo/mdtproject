# 근거 문서

규준 수치를 기억으로 채우면 그럴듯하지만 틀린 룰팩이 나온다. 룰팩의 모든 수치는 아래 문서의 특정
판·쪽에 연결되어야 하고, 쪽을 특정하지 못한 값은 `confidence: inferred`로 남는다 (ADR-015).

## 수량적산기준에서 직접 확인한 값

ADR-013·ADR-014의 근거이자 골든테스트 픽스처의 출발점이다.

- **6쪽** — 수량은 **設計数量·計画数量·所要数量** 세 가지로 정의된다
- **6쪽** — 所要数量은 「定尺寸法による切り無駄や、施工上やむを得ない損耗を含んだ数量」
  → **정척 절단 로스는 표준 할증률에 이미 포괄되어 있다.** 절단 조합 최적화는 범위 밖이다
- **20쪽** — 「鉄筋について、その所要数量を求めるときは、その設計数量の４％の割増を標準とする」
- **13쪽** 山留め壁 철근 3% 증 / **14쪽** 말뚝 철근 3% 증
  → **4%는 躯体 철근 한정이다.** 할증률 룰은 부재 구분을 인자로 받고 범위 밖이면 실패한다 (ADR-014)

## 제외 — 건축공사 표준상세도 (令和4年改定)

https://www.mlit.go.jp/common/001157902.pdf

**M0에서 확인 완료 (2026-08-09). 제외를 확정하고 조건부 복귀 항목을 닫는다.** 상세는 `docs/M0-FINDINGS.md`.

- 이 PDF가 3쪽인 것은 결손이 아니다. `建築工事標準詳細図（令和4年改定）`은 **6개 PDF로 나뉜 한 벌**이고
  `001157902.pdf`는 그중 **(1)권(표지·총칙·표시기호)**이다. 본편은 (2)~(6)권 115쪽으로 실재한다
- **그러나 본편 115쪽 전체에 柱·大梁 배근 상세도가 없다.** `主筋`·`帯筋`·`あばら筋`·`定着長さ`·
  `重ね継手長さ`·`かぶり厚さ`·`配筋要領` 검색 일치 0건. 수록 내용은 마감·건구·잡철물·옥외 배수이고,
  걸리는 `鉄筋`은 側溝·맨홀 같은 옥외 구조물의 `D10-@200` 부류다
- 1권 총칙이 목적을 「설계에서 사용빈도가 높은 상세의 표준화」로 적는다 — **마감·잡부 상세도이지
  구조 배근도가 아니다.** 배근 상세가 들어갈 자리가 애초에 아니었다
- **R7 대응판은 없다.** 최신이 令和4年改定이고 R7 표준시방서 페이지에도 링크가 없다. 1권 총칙이
  근거를 「公共建築工事標準仕様書 **令和4年版**」으로 명시해 판도 어긋난다

제외 사유가 「PDF가 잘렸다」에서 **「이 문서에는 배근 상세가 애초에 없다」**로 바뀐다. 실질 영향은
바뀌지 않는다 — **배근 상세의 유일한 근거는 `標準仕様書 5章`이다.** M0 측정 결과 5장에 MVP 관련
수치 약 92개가 텍스트로 있고, 8개(フック余長 4 · 継手位置 4)만 이미지에 갇혀 있다.

본편 6권의 URL과 해시는 재조사 비용을 없애기 위해 남긴다 (전부 `https://www.mlit.go.jp/common/` 아래).

## 아직 확보하지 못한 것

- **JIS G 3112** 철근콘크리트용 봉강 — 적용 판과 **단위질량표.** 철근 kg 산출의 필수 입력이므로 확보
  전에는 물량 집계를 완성할 수 없다. M2의 선행조건
- **JASS 5** — MVP 근거는 아니다(ADR-003). 민간공사 대응 룰팩을 만들 시점의 전제

창소프트 제품군(https://chang-soft.com/products/)은 제품 참고일 뿐 규준 수치의 정본으로 쓰지 않는다.

## 적용 범위의 한계

공공건축 기준은 국토교통성 관청영선이 **관청시설**에 쓰는 기준이고, 일본 민간 공사는 JASS 5 기반이
주류다. 산출 근거가 공공건축 기준임을 UI 하단에 고정 표시한다 — 계약도서가 다른 기준을 채택한
현장에서는 값이 다를 수 있다.

계약도서·구조도·특기시방이 상충하면 **코드가 해석하지 않는다.** 도면·특기값이 우선이라는 실무 관행에
따라 사용자가 최종 값을 입력값으로 넣는다.

## 골든테스트 픽스처

`tests/golden/`의 픽스처마다 출처 문서·판·쪽·표와 입력 조건, 기대값, 반올림 정책을 함께 적는다.
쪽·표가 없는 픽스처는 사후 대조가 불가능하므로 등록하지 않는다.

골든테스트가 판정하는 것은 "엔진 출력이 픽스처와 일치하는가"까지이고 "픽스처가 원문을 옳게 옮겼는가"는
판정하지 못한다(ADR-010). 쪽·표 기록이 그 층의 유일한 방어선이다.
