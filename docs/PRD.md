# PRD: Kijun (基準)

## 목표
일본 공공건축 기준(`公共建築工事標準仕様書`·`공공건축 수량적산기준`)에 근거해, 브라우저에서 간이 평면과 부재 단면일람을 입력하면 柱·大梁의 배근상세를 산정하고 물량 내역서와 3D 모델을 산출하는 웹 도구.

### 이 제품이 자동으로 정하는 것과 정하지 않는 것

구조해석·구조설계를 하지 않는다. 사용자가 단면일람에 입력한 主筋 경·본수, 帯筋/あばら筋 경·피치를 **그대로 사용**하고 다음만 산정한다.

- 定着長さ, 重ね継手長さ, 折曲げ 형상, かぶり厚さ 적용
- 철근 개체의 형상과 길이, 본수 전개
- 부재별 철근 設計数量·所要数量

필요한 主筋 양·경·본수와 전단보강근 피치를 구조적으로 결정하지 **않는다.**

## 사용자
일본 RC 골조의 철근 물량을 뽑는 사람 — 적산 담당자, 견적 담당자, 소규모 설계·시공 사무소.

MVP 단계의 실질 사용자는 다음 두 부류로 나뉜다.

| 대상 | 검증 항목 | 접근 방법 |
|---|---|---|
| 일본 실무자 | (미확보) | MVP 완성 이후 과제 |
| 한국 실무자 | UX만 — 입력 흐름, 내역서 양식, 빠진 항목 | 지인 네트워크 |

**숫자의 정확성은 사람이 아니라 골든테스트가 판정한다.** 이 분리를 섞지 않는다.

단 골든테스트가 판정하는 것은 "엔진 출력이 전사된 표와 일치하는가"까지다. **"원문을 옳게 읽고 옳게 전사했는가"는 판정하지 못한다.** 원문 추출은 LLM이 대행하지만 추출자와 승인자가 같으면 독립 검토가 아니므로, 그렇게 채운 값은 `inferred`로 남고 워터마크 대상이 된다 (ADR-010, ADR-015).

## 핵심 기능
1. **간이 평면 입력** — 브라우저 그리드에 柱·大梁을 배치하고, 부재 단면일람(主筋 경·본수, 帯筋/あばら筋 경·피치)을 표로 입력한다. DWG 도면 인식은 하지 않는다.
2. **룰팩 기반 배근상세 산정** — 定着長さ, 重ね継手長さ, 折曲げ 형상, かぶり厚さ를 룰팩에서 조회해 철근 개체의 형상·길이·본수를 확정한다. 규준 수치는 코드가 아니라 데이터에서 온다.
3. **물량 내역서** — 부재별 철근 리스트(경·본수·길이·산출식)와 設計数量·所要数量(躯体 4% 할증) 집계. Excel/PDF 내보내기.
4. **3D 뷰어** — three.js로 생성된 철근을 확인. 내역서 행 ↔ 3D 철근 개체 상호 선택. glTF/GLB 내보내기.
5. **출처 추적** — 모든 규준 수치에 근거 문서·판·쪽과 원문 URL 링크가 붙는다. `inferred`(원문 미확인·추론으로 채운 값)는 UI에서 경고 표시하고, 그 값이 계산에 기여한 내보내기 산출물에는 워터마크가 붙는다.

## MVP 제외 사항
- **구조해석·구조설계** — 主筋 경·본수와 帯筋/あばら筋 피치는 사용자 입력이며 제품이 바꾸지 않는다 (ADR-012)
- **DWG/DXF 도면 자동인식** — 검증용 실도면 데이터가 없어 1인 개발로 불가능
- **壁·スラブ·基礎·小梁** — 특히 벽 개구부 보강근은 관행 의존도가 높아 검증 불가 (ADR-005)
- **콘크리트·거푸집 물량** — 철근만 낸다. 거푸집 면적은 개구부 공제 등 또 하나의 룰 세트와 형상 입력 UI를 요구한다. v1.1 (ADR-005)
- **배근시공도(2D) 출력** — 가장 비싸고 관행 의존적
- **IFC 내보내기** — Revit/Navisworks 호환성을 검증할 방법이 없음
- **계정·DB·과금·팀 기능** — 고객이 생긴 뒤에 붙인다
- **JASS 5 / 발주처 특기시방서 룰팩** — 근거 문서를 国交省 공개 자료로 고정한다 (ADR-003)
- **절단 로스·이음 개소 최적화** — 所要数量의 표준 할증률이 정척 절단 로스를 이미 포괄한다(수량적산기준 6쪽). 절단 조합 최적화는 별개 문제이며 범위 밖이다
- **계산 DAG** — 숫자 클릭 → 전체 계산 경로 역추적. MVP는 행 단위 산출식과 룰팩 출처 링크까지. 전체 DAG는 v1.1
- **일본어 UI 전문 검수** — `ja`가 기본 로케일이지만 원어민 검수는 하지 않는다

## 디자인
- 라이트 모드 기본. 도면 작업은 흰 바탕이 실무 관례이고, 물량표는 인쇄·캡처되어 공유된다.
- 3D 뷰 캔버스만 어두운 배경. 철근을 강조하기 위함.
- 무채색 + 포인트 1색. 포인트 색은 "선택된 부재/철근"에만 쓴다. 철근 경(D10~D32)을 색으로 구분하지 않는다 — 색 12개는 읽히지 않는다.
- 화면은 3분할: 좌측 평면 에디터 / 우측 상단 3D 뷰 / 우측 하단 물량 내역서. 세 패널이 같은 선택 상태를 공유한다.
- `confidence: inferred` 값이 계산에 쓰인 행에는 경고 아이콘을 붙이고, 내보내기 산출물에는 워터마크와 기여 항목 목록을 넣는다. 이것이 이 제품의 신뢰 장치다.
- 設計数量과 所要数量은 같은 표에 나란히 두되 열을 시각적으로 분리한다. 発注에 쓰는 숫자가 어느 쪽인지 헷갈리면 안 된다.
- 규준 수치의 출처는 **클릭 가능한 링크**로 노출한다. "누구든 클릭 한 번으로 원문과 대조할 수 있다"가 ADR-003이 이 근거 문서를 고른 이유이므로, 링크를 죽이면 근거 선택의 이유가 사라진다.
